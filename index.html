1. O que é DOM? Explique com suas palavras e a relação com HTML

é a forma como o navegador entende e organiza o seu HTML na memória, transformando cada tag em um "objeto" manipulável por linguagens de programação, como o JavaScript

2. O que é um nó (node)? Explique elementos, atributos e textos.

nó (node) é a unidade fundamental de um documento HTML ou XML. O DOM representa o documento como uma estrutura de árvore, onde cada parte — tags, texto, comentários e atributos — é considerada um nó individual.

3. Explique os métodos: getElementById(), querySelector(), querySelectorAll().

getElementById() Este é o método mais específico e performático para buscar um elemento único através do seu atributo id;

querySelector() É um método versátil que permite selecionar elementos usando qualquer seletor CSS (ID, classe, tag, atributos, etc.);

querySelectorAll() Funciona de forma idêntica ao querySelector, mas em vez de parar no primeiro resultado, ele captura todos.

4. Diferença entre innerHTML e innerText

o innerHTML processa e renderiza tags HTML, permitindo alterar a estrutura do DOM, enquanto o innerText manipula apenas texto, exibindo tags como texto puro. O innerHTML retorna o conteúdo com formatação, já o innerText retorna apenas o texto visível e ciente do CSS

5. O que são eventos? Exemplos: onclick, onchange, onmouseover.

Em programação web (JavaScript), eventos são ações, ocorrências ou sinais que acontecem no sistema que estamos desenvolvendo — geralmente provocados pelo usuário ou pelo navegador — aos quais o código pode responder de forma interativa
